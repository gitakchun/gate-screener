# gate-screener

Gate.io USDT 무기한 선물 전 종목을 조건으로 거르는 웹 스크리너입니다.
공개 시세만 쓰므로 API 키가 필요 없고, Python 표준 라이브러리만 사용합니다.

## 구조

- `build_data.py` — 전 종목의 1시간봉(최근 14일)을 받아 기간별 요약을 `site/data.json`으로 저장
- `site/index.html` — 화면. `data.json`과, Gate API에서 직접 받는 실시간 시세(20초마다)를 합쳐 계산
- `.github/workflows/update.yml` — GitHub Actions가 10분마다 `build_data.py`를 돌리고 `site/`를 GitHub Pages에 배포

GitHub 예약 실행은 몇 분~수십 분 늦을 수 있어서, 기간 상승률·일별 상승률의 과거 부분은 그만큼 늦을 수 있습니다.
현재가·24h 변동·거래대금·펀딩비는 항상 실시간입니다. 화면 상단에 데이터 시각이 표시됩니다.

공개 저장소에서 60일 동안 커밋이 없으면 GitHub가 예약 실행을 멈춥니다.
Actions 탭에서 다시 켜거나 아무 커밋이나 올리면 됩니다.

## 로컬 실행

```bash
python3 build_data.py --serve        # http://localhost:8765, 5분마다 갱신
python3 build_data.py --serve --host 0.0.0.0   # 같은 와이파이의 휴대폰에서도 접속
```

## 지표

| 항목 | 의미 |
|---|---|
| N일 전 가격 대비 현재 | 정확히 N×24시간 전 종가 대비 현재가 (상장 N일 미만이면 첫 봉 대비) |
| N일 내 저점 대비 현재 | 최근 N일 최저가 대비 현재가 |
| N일 내 저점→고점 최대 상승 | 최근 N일 최저가와 그 이후 최고가 사이 상승폭 (지금 떨어졌어도 잡힘) |
| 일별 상승률 (MM/DD) | 한국시간 자정 기준 그날 종가 ÷ 전날 종가. 오늘 칸은 현재가 기준 |
| 거래량 배수 | 최근 24시간 거래대금 ÷ 그 전 7일 하루 평균 거래대금 |
| 신규 n일 | 상장 후 N일이 안 된 종목 |
