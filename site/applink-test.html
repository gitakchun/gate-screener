Gate 앱 링크 테스트 (BTC 선물)

아이폰에서 하나씩 눌러 보고, Gate 앱이 바로 열린 번호를 알려 주세요. 브라우저로 가면 뒤로 가기 후 다음 번호를 눌러 주세요. "주소가 유효하지 않음" 같은 창이 떠도 괜찮습니다.

  1. gate.com 선물 (같은 탭)
  2. gate.com 선물 (새 탭) — 지금 스크리너 방식
  3. gate.com (www 없이)
  4. gate.io 선물
  5. gate.com 한국어 경로
  6. gate.com 현물
  7. gateio:// (앱 직접 실행)
  8. gate:// (앱 직접 실행)
  9. gateioapp:// (앱 직접 실행)

1~6번을 꾹 눌렀을 때 메뉴에 "Gate에서 열기"가 보이는지도 알려 주시면 좋아요.
